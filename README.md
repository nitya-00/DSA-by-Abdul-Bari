

# DSA – Data Structures & Algorithms by Abdul Bari

A collection of fundamental DSA problems and algorithm implementations in C++, covering essential data structures and their operations.

The concepts are primarily learned through **Abdul Bari's Data Structures and Algorithms lectures**, focusing on understanding core algorithms and building strong problem-solving fundamentals.

### Topics Covered
- **Arrays** – Basic operations and algorithms
- **Linked Lists** – Singly, Doubly and Circular Linked Lists
- **Stacks** – Implementation and applications
- **Queues** – Simple Queue, Circular Queue and Deque
- **Graphs** – Representation, BFS and DFS

### Objective
To strengthen DSA fundamentals through hands-on implementation and understanding of essential algorithms.

**Language:** C++
